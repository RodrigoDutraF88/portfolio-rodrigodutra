# Rodrigo Dutra, Portfolio

My personal portfolio built with Next.js, TypeScript and Tailwind CSS v4, in three languages (PT/EN/IT) with light and dark themes.

🔗 **Live:** https://portfolio-rodrigodutra.vercel.app

**English** · [Português](#português) · [Italiano](#italiano)

## English

My personal portfolio: projects, skills, and how to reach me.

**Stack:** Next.js (App Router) · React · TypeScript (strict) · Tailwind CSS v4 · next-intl (pt/en/it) · deployed on Vercel.

```bash
npm install
npm run dev     # http://localhost:3000
```

**Scripts:** `dev`, `build`, `start`, `lint`, `typecheck`, `format`, `i18n:check`.

More in [`docs/`](docs/): [STRUCTURE](docs/STRUCTURE.md) · [SETUP](docs/SETUP.md) · [DEPLOYMENT](docs/DEPLOYMENT.md) · [STYLE-GUIDE](docs/STYLE-GUIDE.md).

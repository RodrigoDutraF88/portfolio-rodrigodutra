# Rodrigo Dutra — Portfolio

My personal portfolio. It shows who I am, the projects I have built, and how to reach me.
Built with Next.js and TypeScript, styled with Tailwind, and written in Portuguese first with
English and Italian versions.

## Stack

- Next.js (App Router) and React
- TypeScript in strict mode
- Tailwind CSS v4
- next-intl for pt, en, and it
- Deployed on Vercel

## Running it locally

```bash
npm install
npm run dev
```

The app runs at http://localhost:3000.

## Scripts

| Script                 | What it does                      |
| ---------------------- | --------------------------------- |
| `npm run dev`          | Start the dev server              |
| `npm run build`        | Production build                  |
| `npm run start`        | Serve the production build        |
| `npm run lint`         | Run ESLint                        |
| `npm run typecheck`    | Type check with tsc               |
| `npm run format`       | Format the codebase with Prettier |
| `npm run format:check` | Check formatting without writing  |
